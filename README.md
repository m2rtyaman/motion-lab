# Motion Lab

**A deterministic motion-graphics studio for frame-accurate video.**
Motion is written as code, validated by static gates, and rendered to MP4 at 60 FPS — never generated by a black box.

## What Motion Lab is

Motion Lab is a React-based production environment for motion design. A video is
described by three files, checked by a stack of automated audits, and rendered by
Remotion with GSAP timelines.

| Stage | Artefact | Purpose |
| --- | --- | --- |
| Direction | `src/projects/<slug>/direction.md` | Concept, physics, typography, depth layers. |
| Contract | `src/projects/<slug>/spec.json` | Beat timeline, camera keyframes, easing, SFX cues. |
| Implementation | `src/projects/<slug>/Scene.tsx` | Deterministic scene built from shared primitives. |

Every animation frame is a pure function of `frame / fps`. The same commit
produces the same pixels on every machine, at 60 FPS, in 9:16 or 16:9.

**Core stack:** React 19, Remotion 4, GSAP 3, TypeScript, Vite, Tailwind CSS 4.

---

## What it is not

- **Not a text-to-video model.** There is no prompt-to-pixels step. Every visual
  is a component you can read, diff, and review.
- **Not a slide-deck exporter.** Scenes are continuous stages, not crossfaded
  slides.
- **Not a dashboard mockup kit.** Consumer and brand videos use authentic product
  anatomy, not invented server telemetry.
- **Not a hosted service.** It runs locally, with no API keys and no external
  accounts.

## Design constraints

These are enforced by the audits in [`scripts/`](scripts), not just documented.

| Rule | Enforcement |
| --- | --- |
| Animate only `transform`, `opacity`, `filter` | `audit:ast` rejects layout-property tweens (`top`, `width`, `height`, ...). |
| Deterministic timelines only | Animation runs through `useRemotionGSAP` and `tl.seek(frame / fps)`; `setTimeout` and raw CSS transitions are rejected. |
| No unseeded randomness | `Math.random` is banned; procedural variation uses seeded `mulberry32`. |
| No neon glow, purple/cyan gradients, floating bento cards | `audit:slop` scans palettes, shadows, and shell anchoring. |
| No micro-type | `audit:slop` enforces minimum readable sizes in broadcast viewports. |
| No dead frames | `audit:critic` flags holds longer than the allowed threshold and enforces a 1.2 s readability hold on final messages. |
| No `.tsx` / `spec.json` drift | `audit:spec` cross-checks beats, camera keys, and scene code. |
| No glyph or encoding surprises | `audit:glyph` validates Turkish and international typography. |

## Architecture

Motion Lab separates **engine**, **vocabulary**, and **content**:

```
src/
  core/          Deterministic bridge, tokens, recipes, math, audio, contracts
  primitives/    Reusable staged components (28) — cameras, cards, typography, textures
  world/         2.5D world stage and CharacterActor sprite system
  vfx/           Shockwaves, particles, and procedural light
  archetypes/    Editorial archetype cards (metric telemetry, workflows, ...)
  projects/      One isolated project per video (16 reference projects)
  templates/     23 declarative template kits (React + hydrated HTML bridges)
  remotion/      Composition entry point and registry
  stage/ camera/ motion/ materials/ procedural/   Supporting layers

.agent/skills/   20 studio skills — workflow instructions for agents and humans
scripts/         CLI, quality gates, renderer, asset harvesters
references/      Style guides, storyboard constitution, B-roll examples
public/          Fonts, CC0 sound effects, audio beds
out/             Rendered outputs (git-ignored)
```

The engine layer is intentionally small. Content lives in projects; reusable
behaviour lives in primitives and `src/core`. A project never forks the engine.

## Installation

```bash
git clone https://github.com/m2rtyaman/motion-lab.git
cd motion-lab
pnpm install
```

`pnpm install` also configures the repository git hooks (`core.hooksPath`).

## Quick start

### 1. Render an existing project

```bash
pnpm render --project single-container-broll
```

Output: `out/single-container-broll/single-container-broll.mp4`.

### 2. Inspect a scene before rendering

```bash
pnpm check --project single-container-broll
pnpm render:contact-sheet --project single-container-broll
```

The contact sheet writes `out/<slug>/visual-audit-grid.png` at beat boundaries.

### 3. Create a new video

```bash
pnpm new my-product --mode editorial-ui --aspect 9:16 --duration 12
```

This scaffolds `direction.md`, `spec.json`, and `Scene.tsx`, then updates the
generated project registry.

### 4. Open the interactive preview

```bash
pnpm studio:preview
```

### Useful commands

| Command | What it does |
| --- | --- |
| `pnpm check` | Runs the full static quality gate across all projects. |
| `pnpm doctor` | 14-point repository health audit. |
| `pnpm gate --project <slug>` | Pre-render checklist for one project. |
| `pnpm inspect --project <slug> --frame <n>` | Extracts and inspects a single frame. |
| `pnpm studio:brief --project <slug>` | Generates a 7-part director brief. |
| `pnpm music:map --project <slug>` | Builds a beat map from an audio track. |
| `pnpm render:still --project <slug>` | Renders a single still for review. |

## The four orchestration modes

| Mode | Use for | Signature |
| --- | --- | --- |
| `editorial-ui` | SaaS, fintech, product demos | Hardware shells, hairline subgrids, live SVG data, 3D camera glide. |
| `cinematic-world` | Games, narrative, 2.5D worlds | Character actor, procedural lighting, impact VFX, squash-and-stretch. |
| `kinetic-poster` | Ads, manifestos, social drops | Full-bleed typography, rhythmic masked splits, beat-locked cuts. |
| `hybrid-orchestrated` | Multi-archetype stories | A hero actor that morphs across sections without a cut. |

The router that selects a paradigm lives in
[`.agent/skills/studio-router`](.agent/skills/studio-router/SKILL.md).

## Quality gates

`pnpm check` is the single entry point; it runs the individual audits below.

| Audit | Command | Checks |
| --- | --- | --- |
| Spec | `pnpm audit:spec` | Beat continuity and code-to-contract sync. |
| Storyboard | `pnpm audit:storyboard` | Beat tables against the storyboard constitution. |
| AST | `pnpm audit:ast` | Layout reflows, magic durations, nondeterminism. |
| Motion | `pnpm audit:motion` | Dead holds and beat unmounting. |
| Slop | `pnpm audit:slop` | Neon palettes, micro-type, floating cards, fake telemetry, mode purity. |
| Craft | `pnpm audit:craft` | Spring physics, CSS 3D/SVG purity, stage anchoring. |
| Visual | `pnpm audit:visual` | Blank frames and visual regressions. |
| Critic | `pnpm audit:critic` | Director scoring, readability, anticipation, P0/P1/P2 triage. |
| Glyph | `pnpm audit:glyph` | Character encoding and typographic safety. |
| Templates | `pnpm audit:templates` | Template manifest integrity. |
| Doctor | `pnpm audit:doctor` | 14-point repository health diagnostic. |

A render is expected to pass **every** gate. Passing the TypeScript compiler is
not sufficient, and passing a linter is not approval.

## Templates, references, and skills

### Templates — `src/templates/` (23)

Declarative kits for common formats: Swiss grids, data rollups, kinetic
typography, product promos, light leaks, logo outros, and more. Each template
records its engine version, supported aspects, and upstream attribution in
`template.html-video.yaml`.

### References — `references/`

- [`MOTION_LAB_STYLE_GUIDE.md`](references/MOTION_LAB_STYLE_GUIDE.md) — 24 visual
  style families and their negative constraints.
- [`MASTER_STORYBOARD_RULES.md`](references/MASTER_STORYBOARD_RULES.md) — the five
  universal storyboard laws and the 3-layer depth system.
- [`GOLDEN_REFERENCE.md`](references/GOLDEN_REFERENCE.md) — the single-container
  benchmark and anti-pattern log.
- [`prompts/`](references/prompts/) — seven production prompt archetypes.
- [`broll-examples/`](references/broll-examples/) — six HTML B-roll interactions.

### Skills — `.agent/skills/` (20)

The skills encode the studio's workflow: direction, choreography, engineering,
critique, audio, and asset harvesting. Start with `studio-router`,
`motion-director`, `motion-playbook`, and `remotion-engineer`; run
`adversarial-visual-critic` and `anti-slop-auditor` before any render.

## Audio and typography

- **Sound effects:** 117 CC0 files in 13 categories under `public/sfx/`.
  `SoundCuePlayer` places cues frame-accurately and targets −16 LUFS with true
  peaks below −4 dBFS. Per-kit credits: [`public/sfx/LICENSES.md`](public/sfx/LICENSES.md).
- **Typography:** self-hosted `.woff2` subsets in `public/fonts/` (Inter,
  JetBrains Mono, Space Grotesk, Syne, Bebas Neue, Playfair Display, and more).
  Font licenses are recorded in [`NOTICE`](NOTICE).

## Versioning and releases

Motion Lab follows [Semantic Versioning](https://semver.org/). The current line
is **0.8.0**, published as a **pre-release**.

- `0.8.x` — fixes only; render output is expected to be stable within the line.
- `0.x.0` — may introduce breaking changes to schemas, APIs, or CLI flags.
- `1.0.0` — first stable release.

Release notes live in [`CHANGELOG.md`](CHANGELOG.md). Git tags use the `v`
prefix (`v0.8.0`).

## Contributing

1. Branch from `main` using `feat/`, `scene/`, `fix/`, `docs/`, or `chore/`.
2. Follow Conventional Commits.
3. Run `pnpm check` and `pnpm audit:doctor` locally.
4. Open a pull request and complete the template checklist.
5. PRs are merged with **Squash and Merge**.
