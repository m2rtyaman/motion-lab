# AUTONOMOUS MULTI-PROJECT MOTION GRAPHICS STUDIO (MANDATORY LIFECYCLE)

This repository is a deterministic, multi-project motion graphics studio producing broadcast-grade 9:16 vertical and 16:9 horizontal video content at 60 FPS.
Every scene/video is maintained as an isolated project under `src/projects/<slug>/`.

---

### ARCHITECTURE & DIRECTORY STRUCTURE
```
src/
  projects/
    <slug>/
      direction.md      # Concept, visual depth & physics decisions
      spec.json         # Motion contract (beats, camera choreography, SFX cues)
      Scene.tsx         # Project-specific scene component
      vision-notes.md   # Visual audit observations and sign-offs
    registry.generated.ts # Dynamic registry generated by scripts/gen-registry.mjs
  core/                 # Shared deterministic bridge, tokens, and gold-standard recipes
  primitives/           # SpotlightStage, CameraRig, KineticText, SpecularCard, EditorialSpecimenStage, TactileProductStage, MobileStingStage, PapercraftCutoutStage
  world/                # WorldStage, CharacterActor (2.5D Sprite environment)
  vfx/                  # ShockwaveRoar, AtmosphereParticles
  archetypes/           # Editorial glass archetype cards (MetricTelemetry, etc.)
out/
  <slug>/
    <slug>.mp4          # Final rendered video output
    visual-audit-grid.png # 2x2 or 4x4 visual self-audit contact sheet
    vision/manifest.json# Sampled frame captures and inter-frame motion delta analysis
```

### NEW VIDEO PRODUCTION LIFECYCLE (5 STEPS)

#### 1. Project Scaffolding
Execute the following in the terminal:
`pnpm new <slug> --mode <cinematic-world | editorial-ui | kinetic-poster | hybrid-orchestrated> [--aspect 9:16 | 16:9] [--duration 6]`
This scaffolds valid `direction.md`, `spec.json`, and `Scene.tsx` files under `src/projects/<slug>/` and updates the project registry.

#### 2. Direction & Motion Contract (Motion Director & Choreographer)
- `src/projects/<slug>/direction.md`: Define concept, physics, and typography. Per `references/MASTER_STORYBOARD_RULES.md`, document the **3-Input Separation of Concerns** (Script: What & Why, Storyboard: Visual Depth & Anatomy, Motion Reference: Motion Dynamics) and the **3-Layer Depth System** (Base -> Ghost Outline -> Foreground Hero).
- `src/projects/<slug>/spec.json`: Establish the exact second-and-frame Storyboard Timeline (1.0–1.5s micro-beats, camera keyframes, ease curves, SFX triggers, and a final Stillness Hold of at least 1.2s / 72 frames).
- Verification: `pnpm audit:spec --project <slug>` and `pnpm audit:storyboard --project <slug>`

#### 3. Deterministic Engineering (Remotion Engineer)
- Implement `src/projects/<slug>/Scene.tsx`.
- Animation must be constructed exclusively via the `useRemotionGSAP` hook with `tl.seek(frame / fps)` determinism.
- GPU Purity: Tween only `transform`, `opacity`, and `filter`. Timing and spring constants must derive from `tokens.ts` and `recipes.ts`; zero magic numbers or forbidden ease functions (`linear`, `easeInOut`).

#### 4. Multi-Layered Quality Gate (Linter, Critic & Vision Loop)
Execute static and visual audits:
`pnpm check --project <slug>`
- `audit:spec`: Beat continuity, camera stillness check, and code-spec synchronization.
- `audit:ast`: Babel AST parser scan for magic durations, layout-triggering tweens, nondeterminism, and raw CSS transitions.
- `audit:slop`: Neon/purple-cyan glow check, micro-font audit (min 18px), mode purity, Hardware Shell anchor, and semantic residual-value verification.
- `audit:craft`: Motion Studio v5.0 visual craftsmanship, pure CSS 3D/SVG determinism, spring physics, and stage anchoring.
- `audit:critic`: Opus Animation Guide Prompt 10 director scoring engine (Dead time >0.5s check, 1.2s minimum text readability rule, P0/P1/P2 prioritization).
- `adversarial-visual-critic`: Zero-tolerance anti-AI-slop visual gate. Floating disconnected bento cards, neon glow vomit, and raw slide transitions are blocked before rendering.
- `render:contact-sheet --project <slug>`: Automated beat boundary frame captures generating `out/<slug>/visual-audit-grid.png`.
- Visual model inspection with frame-referenced (`f130`) notes documented in `src/projects/<slug>/vision-notes.md`.

### OPUS ANIMATION GUIDE & ADVERSARIAL VISUAL CRITIC GOLDEN LAWS (MANDATORY RULES)
1. **Authentic Motion Graphics DNA (Ban on Fake SaaS Admin Panels):** The studio's DNA is not displaying static web dashboards (Linear/Raycast mockups); it is creating **genuine motion graphics**:
   - Typography tearing across the screen,
   - Dynamic geometric shapes slicing full-bleed space,
   - Dramatic scale leaps (20x zoom from a micro detail into a full-bleed cinematic universe),
   - Rhythm, beat punches, and authentic brand interface anatomy.
   The agent must think like a seasoned motion designer, never placing screensaver-like fake SaaS telemetry boxes.
2. **Single Container & Hero Continuity Anchor (Container Dogma Forbidden):** In inter-scene transitions, a single hero actor (`TheHeroActor`) or focus anchor must evolve without cutting, altering form, scale, and position (**Peak Velocity Container Morphing**). However, this rule must never be used as an excuse to center a fixed 1380px dark box with 4 nested telemetry tiles. The actor can explode into a full-bleed cinematic video player, evolve from a search bar, or lock into a monumental brand emblem.
3. **Vibrant & Authentic Brand Canvas (Ban on Dark-Mode Blindness):** The studio is not imprisoned in dark cyber themes (`#0B0B0E`, `#050706`). YouTube (`#FFFFFF` / `#F9F9F9` / `#FF0000` / `#0F0F0F`), Apple Light, Google Material, Spotify, and other global brands' authentic light and vibrant palettes are first-class citizens. The canvas breathes in the true palette of the brand.
4. **Authentic Interface Anatomy (Zero Fake DevOps Slop):** In consumer, media, entertainment, and brand videos, outputting made-up server telemetry (`Zero-Downtime POP Mesh`, `enclave-lon1-v4`, `ops/sec`, and similar cyber fills) is STRICTLY FORBIDDEN (P0 violation). Rebuild authentic product anatomy:
   - For YouTube: Clean white YouTube Header (top-left logo, pill-shaped center search bar with magnifying glass, notification bell, user avatar).
   - Left side: Authentic video watch stage (title, channel badge, subscriber count, bold black "Subscribe" pill, Like/Share action pills).
   - Right side: Recommended videos feed (curated thumbnail cards).
   - Cinematic interaction: Typing into the search bar, clicking a video, expanding into Theatre Mode, player taking over the full viewport!
5. **Architectural Stage & Anchor Framework:** UI elements must never float aimlessly in void space; they must be anchored within defined stage components (`FullScreenStage`, `FullBleedStage`, `AuthenticBrandShell`, `BrowserFrame`, `KineticVectorStage`, `CameraRig`, `SpotlightStage`).
6. **Subgrid Shared Borders & Hairline Matrix:** Hardware-like panels must use CSS Grid with `gap: 1px` where background luminosity bleeds through hairline borders (`gap-[1px] bg-white/[0.08]`).
7. **Zero Redundancy Typography Rule:** Marketing headlines communicate the **benefit**, while UI tags explain the **background action**. The exact same phrase must never be repeated between headline and UI badge.
8. **Anticipatory Stillness (300–600ms):** Prior to every major visual punch, theatre mode expansion, or transition, insert 300–500ms of micro-stillness to multiply the impact.
9. **Readability Hold Duration:** The final message, logo resolve, and call-to-action (CTA) must remain crystal clear on screen for **at least 1.2 seconds (72 frames @ 60 FPS)**. Rhythmic interstitial kinetic words may punch and exit within 8–25 frames without freezing the pacing.
10. **Contextual Easing:** Snappy springs for UI elements, smooth decelerations (`expo.inOut` / `power3.out`) for camera moves, controlled damping for brand logos.
11. **Deterministic Pseudo-Randomness (Mulberry32 / Seeded Random):** `Math.random` is strictly forbidden; all variation must be derived from `t` or seeded pseudo-random algorithms (`seed: 42`).
12. **Slide Stack Ban & Kinetic Handoff:** Scenes must not be arranged as disconnected `absolute inset-0` containers crossfading opacity. The scene must unfold on a single living canvas where elements transfer momentum and geometry through an unbroken **Kinetic Handoff Chain**.
13. **Continuous Hero Actor Law:** Crossfade dissolves between scenes are strictly forbidden. `TheHeroActor` remains physically on stage from frame 0 to the final frame ($opacity > 0$), morphing to drive narrative momentum.
14. **Subagent-Driven Adversarial Critique Gate:** Verification is never delegated purely to static linters. `adversarial-visual-critic` and `anti-slop-auditor` ruthlessly evaluate whether a composition is genuine motion design or lazy template fill.
15. **Master Storyboard Constitution & 5 Universal Laws:** All storyboards strictly implement the principles in `references/MASTER_STORYBOARD_RULES.md`.
16. **Zero API Key Mandate (Fully Keyless Determinism):** The studio operates 100% API-KEY-FREE. No component, script, or CLI tool may require external paid API keys or prompt the user for credentials. Open zero-config EdgeTTS neural audio, millisecond word timing extraction, local cached B-roll (`public/assets/`, `harvest/`), and deterministic procedural motion layers are the required standard.
