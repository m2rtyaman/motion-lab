# 20-SECOND INTERACTIVE APP PROMO WORKFLOW GUIDE
> **Source:** Motion Playbook: Build Motion Graphics with Gemini Omni Flash (20-Second App Promo)  
> **Core Principle:** *"Write the message before designing visuals. The script determines WHAT/WHY is being communicated, the storyboard determines HOW it looks, and the reference video determines HOW it moves (rhythm, cutting grammar, camera choreography)."*  
> **Visual Contrast:** Dark Editor Canvas $\leftrightarrow$ Warm Grid Workspace.

---

## 1. THE 20-SECOND FIVE-STAGE MESSAGE FUNNEL (THE 20S FUNNEL)

```
[0–3s: HOOK] ──> [3–7s: INTRODUCE] ──> [7–14s: DEMONSTRATE] ──> [14–17s: PAYOFF] ──> [17–20s: CTA]
```

1. **0–3s | HOOK:** Dark editor canvas with central logo construction and surrounding 3D tool scatter.
2. **3–7s | INTRODUCE:** Warm grid illuminated workspace (`WarmGridWorkspace`). Soft pill labels, user avatar, and prominent interactive cards.
3. **7–14s | DEMONSTRATE:** Vertical color panels provide a sharp visual reset (`VerticalPanelReset`) $\rightarrow$ Return to dark grid, digital pen write-on handwriting (`WriteOnScript`), cursor micro-actions, and underline emphasis.
4. **14–17s | PAYOFF:** Feature evidence framed within an organic chromatic warp shape (`WarpShapeFrame`).
5. **17–20s | CTA:** Compelling trial invitation and minimalist brand resolve on a deep black ground.

---

## 2. THREE-INPUT SEPARATION OF CONCERNS (THE 3-INPUT RULE)

| Input Stream | Role & Responsibility |
| :--- | :--- |
| **Script** | **WHAT** and **WHY** the commercial speaks (Core narrative message & value proposition). |
| **Still Storyboard** | **HOW IT LOOKS** (Subject framing, color palette, spatial typography placement). |
| **Reference Video** | **HOW IT MOVES** (Pacing, cutting cadence, camera velocity, typography & UI spring physics). |

---

## 3. MICRO-TO-MACRO REFERENCE ANALYSIS

When breaking down motion references, replace generic adjectives ("cinematic", "sleek") with concrete physics:
- **Micro Level:** Subtle UI physics, spring curves, text arrival styles, contact shadows, cursor paths.
- **Macro Level:** Framing, transitions, shot order, tempo, and overarching narrative structure.

### 3 Pillars of Structural Analysis
1. **Motion Grammar:** Cut points, transition vectors, action timing, spring constants, exact frames where motion starts and settles.
2. **Type Treatment:** Font selection, scale hierarchy, tracking, entrance/exit choreography.
3. **Visual Hierarchy:** Primary focal anchor, secondary layers, background ground plane, and closing resolve lock.

---

## 4. TWO-STAGE (0–10s & 10–20s) CONTINUITY PROTOCOL

For 20-second productions:
- Divide into two logical chapters: `Part 1 (0–10s)` and `Part 2 (10–20s)`.
- **The final frame of Part 1** locks as the exact origin coordinates and camera vector for Part 2.
- In Remotion, continuity is maintained deterministically across a single unified `frame / fps` timeline.
